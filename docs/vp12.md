The replay log hashes the tested source bytes. The committed files remove one trailing blank line each from `scripts/vp12-cases.mjs` and `src/viewport/viewportGeometry.ts`.

The object-only WebGPU preview accepts Add with the default shadow setting and draws without cast shadows. Objects outside the frustum retain their transform, geometry and bounds. Display draws share a material collection and keep scene order. Each object uses a 2 × 2 block in a power-of-two texture atlas. A fixed bilinear sample combines the four texels in linear light. Base colour and Material emission textures use the sRGB transfer function for precision near black. Roughness and metallic use linear textures. Up to 256 visible surfaces have independent draw batches. Larger sets concatenate the same vertices and texture coordinates.

W11 applies Material exposure to the complete scene capture. Studio composites the editor decorations after that pass on the configured WebGPU device. A depth attachment uses the submitted triangle faces, the admitted terrain grid and its skirts. Bulbs and frustums use Field’s ACES and sRGB transforms. Strokes blend at their gizmo opacity. Camera and light hits use the pinned vector picker against the scene, and selection boxes have no selectable owner. GPU readback and screenshots include the displayed helper layer.

In the mixed viewport the editor supplies the live matrices during a drag. After an edit or Undo, WebGPU waits for the editor to apply the same authored object list before using those matrices. The replay checks the parent and child together during the drag and after the native commit. The first Undo restores both objects. Two further Redo and Undo cycles reproduce the committed and original positions in both renderers.
