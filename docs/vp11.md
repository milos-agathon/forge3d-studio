# VP-11 cursor elevation

Run the desktop comparison from the Studio worktree with the VP-04 WebView2, Tauri and Python prerequisites and a clean Field Instrument worktree at `64b7cf09`.

```powershell
node scripts/vp11.mjs
```

The replay opens Field in WebGL2 and Studio with `--disable-webgl`. The candidate must submit the vendored `d6459a26` terrain with no WebGL editor. The command prints its evidence directory and writes `results.json`. All 67 comparisons used trusted WebView pointer input and matched Field on both raw metres and displayed text. Each reading records the browser event and hit target, sampler timestamp, raw metres, client and continuous drawing-buffer coordinates, camera, CSS and drawing-buffer sizes, DPR and cursor text. Field identifies the draw by frame and mesh. Studio identifies it by submission sequence, project generation and terrain object.

Each successful WebGPU submission supplies the camera and drawing-buffer dimensions used for hover. Studio maps the pointer through the displayed canvas rectangle to continuous buffer coordinates and calls the submitted `Camera.screenRay`. The camera aspect comes from that buffer. When fractional DPR rounds the two dimensions differently, Studio centres the canvas, presents square framebuffer pixels and clips the excess at the viewport boundary. If this extends the canvas vertically, the submitted vertical field of view expands proportionally in tangent space. The logical viewport keeps the same focal length as Field.

The forward ray starts at the eye, including inside the near plane and beyond the far plane. It traverses the admitted DEM grid and determines the nearest intersected terrain surface. For a hit, Studio normalizes the pointer against the fractional bounds of the canvas before presentation scaling. It measures the surface in double precision using the submitted Studio pose and the Float32 mesh vertices, NE/SW triangles and world-to-local conversion used by Field. At a shared vertex it can measure the adjoining face on the same patch. A miss immediately clears the readout. VP-06 clicks still use pixel-centre depth, and ground-coordinate queries use bilinear elevation.
