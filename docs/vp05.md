# VP-05 shared cube and DEM depth

From the VP-05 worktree, reproduce the desktop comparison with

```powershell
node scripts/vp05.mjs
```

Use the installed lockfile dependencies, Windows WebView2, the Tauri build tools and a Python with Forge3D and Rasterio. The driver locates the clean Field Instrument worktree at `64b7cf09`. It prints the fresh output directory. Studio starts in Auto with `--disable-webgl` passed to WebView2 before process creation. The context observer records actual requests from the gated startup document and the reloaded fixture.

The cube's Studio UUID names its mesh batch and material slot. Its indexed box has 24 vertices with face normals and 36 indices. With a DEM, Studio subtracts the terrain translation and divides by the VP-04 placement scale before packing the matrix as four rows. With the terrain hidden, the camera and cube share Studio units and an origin snapped to the camera target's nearest 1,024-unit grid point. Studio subtracts that origin before converting either transform to Float32. When an Inspector edit collapses a cube axis below scatter's determinant limit, Studio applies the linear transform to the vertices, recomputes face normals and submits translation in the instance matrix. Solid uses the editor's linear clay colour and roughness. Material supplies the authored linear base colour, metallic and roughness before the viewport's ACES pass.

The fixture uses the VP-01 Bryce view, a 96 Ã— 96 relief preview and the size-2 magenta cube at (0, 0.85, 0). The physical viewport is 794 Ã— 727 at DPR 1. The terrain relief is the only visible cartography layer. Both renderers use the same project lighting. Imagery, modelling and map grids, hillshade, custom HDRI and both shadows are off.

Each `.mask` stores one byte per pixel in top-left row order, with 1 for the cube. The corresponding `.rgba.gz` holds the original framebuffer, and `.png` holds the visible WebView screenshot. Studio uses the runtime's `readRgba()`. Field Instrument uses its live WebGL draw. Both modes compare visible pixels with an independent terrain-only frame inside the isolated cube silhouette. Material also checks for magenta hue. A second Material mask changes only the authored blue channel from 1 to 0, then compares the entire framebuffer at the original pose. The historical 16,014 changed pixels are diagnostic only.
